Diponto Sirene Validator — instalador Windows
==============================================

Versão: {{VERSION}}

INSTALAÇÃO EM OUTRO PC
----------------------
1. Copie o arquivo DipontoSireneValidator-{{VERSION}}-setup.exe para o PC de destino.
2. Execute o instalador (duplo clique). Se pedir, confirme permissão de administrador.
3. Se o Windows SmartScreen avisar (app não assinado):
   "Mais informações" → "Executar assim mesmo".
4. Siga o assistente até concluir.
5. Abra pelo atalho "Diponto Sirene Validator" no menu Iniciar
   (opcional: marque atalho na área de trabalho durante a instalação).

O app será instalado em:
  C:\Program Files\Diponto\Sirene Validator\

PRÉ-REQUISITOS
--------------
- Windows 10 ou 11 (64 bits)
- Microsoft Visual C++ Redistributable (x64), se o app não iniciar:
  https://learn.microsoft.com/pt-br/cpp/windows/latest-supported-vc-redist
- PC na mesma rede do broker MQTT (Mosquitto)
- Impressora Zebra ZT230 USB no PC do posto (recomendado) ou na rede LAN

PRIMEIRA CONFIGURAÇÃO NO PC NOVO
--------------------------------
1. Configurações → host/porta do broker MQTT (ex.: 192.168.51.87:1883).
2. Impressora Zebra:
   a) USB: conecte a ZT230, instale driver Zebra ZPL, escolha "USB (local)"
      e selecione a impressora na lista.
   b) Rede: IP e porta 9100 se houver print server.
   Use "Testar impressão" para validar.
3. Cadastros → cadastre operadores e produtos (SKU com autocalibração).
4. Lote → selecione operador do turno → configure OP e bancada.

DADOS LOCAIS
------------
Histórico, catálogo e fila de sync ficam no perfil do Windows (%APPDATA%),
não na pasta de instalação. Cada PC começa sem os dados do outro —
use backup/restauração em Configurações quando disponível.

DESINSTALAR
-----------
Painel de Controle → Programas → Desinstalar "Diponto Sirene Validator"
ou use o atalho "Desinstalar" no menu Iniciar.

SMOKE TEST (validação rápida)
-----------------------------
[ ] App abre na tela Lote sem erro
[ ] Badge "MQTT OK" (ou conectando) visível na barra superior
[ ] Configurações salva host MQTT
[ ] Configurações → Testar impressão na ZT230 USB
[ ] Cadastros → Operadores lista abre
